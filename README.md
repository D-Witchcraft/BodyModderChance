Body Modder Chance



Source code for the RimWorld mod Body Modder Chance, by D_Witchcraft.



Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3808407877



This repository is provided for public inspection of the mod's source code. The playable mod is distributed through Steam Workshop.



For mod-related questions, bug reports and feedback, please use the Steam Workshop page.



Version note: This repository currently contains the forthcoming v1.1 source code. The Steam Workshop version remains v1.0 until the update is released.
